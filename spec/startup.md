# 起動時の挙動（実装）

- 設定をロード → DB を初期化（必要なら旧 DB を移行）→ Reconcile で vault をスキャン
- 常に新規ファイルを開いた状態で起動
- 起動後はエディタ本文へ自動フォーカスする
- タイプライター方式でスクロールする（`Editor.tsx` の `typewriterScrollPlugin`）
  - 入力・改行・貼り付け・Undo などで、書いている行が画面の垂直中央より下に来たら中央まで持ち上げる
    （文末で書き続けると、書いている行は常に画面中央に留まる）
  - 中央より上で書いている間はスクロールしない（上のほうを直すときに画面が跳ばないように）
  - 上下キーでのカーソル移動には適用しない。WebKit 標準どおり、カーソルが画面外に出たら
    画面中央までスクロールする。ProseMirror が後追いでスクロールすると、
    カーソルの残像が元の位置に残る WebKit の描画不具合が出るため
