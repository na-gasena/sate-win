# スタイルガイド

## カラーパレット（ダークテーマ）
```css
--bg: #1a1a18;          /* ほぼ黒、わずかに暖色 */
--text: #d4d0c8;        /* オフホワイト、青みを抜く */
--text-muted: #6b6860;  /* 文字数カウンター等 */
--accent: #8a8478;      /* 選択状態等 */
```

## カラーパレット（ライトテーマ）
```css
--bg: #f5f2eb;          /* 暖かいオフホワイト */
--text: #2a2820;        /* ほぼ黒、暖色寄り */
--text-muted: #a09890;
--accent: #8a8478;
```

## アニメーション
- ファイルオーバーレイの出現：フェードイン、200ms
- ペインのスライドインは使わない
- トランジションは全体的に控えめに
